# 形象分析助手 - 微信小程序官方知识库

“形象分析助手”是一款基于人体测量学（Anthropometry）、色彩季型理论（Color Season Theory）与视觉美学规则的微信小程序。我们致力于将主观的“变美”转化为可量化、可复制的科学计算。
